## 三分钟体验

```powershell
# 1. 从 GitHub Release 下载 GeWu_x.x.x_x64-setup.exe
# 2. 安装后创建第一个知识库（选择任意文件夹）
# 3. 拖拽文件进去，或点击「扫描」导入现有目录
```

想改个主题？试试社区主题插件：

```powershell
# 在插件管理 → URL 安装，粘贴：
# https://github.com/li360/plugin-theme-midnight
```
