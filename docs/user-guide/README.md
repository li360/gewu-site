# GeWu 用户指南

GeWu（格物）是一个离线优先的个人知识管理桌面应用，帮助你管理本地文件、笔记和知识库。

## 快速入门

### 安装

从 [Releases](../../packages/tauri-app) 页面下载对应平台的安装包。

- **Windows**：双击 `GeWu_x.x.x_x64-setup.exe`，按向导完成安装
- **首次启动**：应用会以默认布局打开，左侧为库管理，中间为目录树和文件列表，右侧为编辑器

### 创建第一个知识库

1. 在左侧"库管理"容器中，点击"新建知识库"按钮
2. 输入知识库名称，选择存储目录（也可直接输入含系统变量的路径，如 `%USERPROFILE%\Documents\我的库`，换机后自动展开到新环境）
3. 点击"创建"后，应用会自动切换到新知识库
4. 知识库目录下会生成 `.kmgr/kmr.db` 数据库文件，用于存储元数据

> **提示**：也可以通过命令行创建：`kmgr init <path> --name <名称>`

### 导入文件

**方式一：扫描目录**
1. 在"库管理"容器中，点击"扫描"按钮
2. 选择要导入的源目录
3. 应用会递归扫描目录下的所有文件并导入元数据
4. 导入完成后，"目录树"和"文件列表"会自动刷新

**方式二：拖拽导入**
- 直接将文件或文件夹拖拽到应用窗口
- 应用会自动识别文件类型并导入

**方式三：命令行导入**
```bash
kmgr scan <知识库路径> --source <源目录>
kmgr add <知识库路径> <文件1> <文件2> ...
```

## 核心概念

### 知识库

知识库是 GeWu 管理文件的基本单位。每个知识库对应一个本地目录，包含：
- 文件夹结构
- SQLite 数据库（存储元数据、分类、标签等）
- 配置信息

### 容器与插件

GeWu 界面由多个**容器**组成，每个容器装载一个**插件**：

| 容器 | 默认插件 | 功能 |
|------|----------|------|
| 库管理 | library-manager | 知识库切换、创建、扫描 |
| 目录树 | folder-tree | 文件夹导航 |
| 文件列表 | file-list | 文件浏览、重命名、删除 |
| 编辑器 | editor / markdown-editor | 文件编辑（按扩展名自动路由） |
| 知识组织 | organizer | 分类、标签管理 |

### 事件流

容器间通过事件联动，例如：
1. 在"库管理"选择知识库 → 自动刷新"目录树"
2. 在"目录树"选择文件夹 → 自动刷新"文件列表"
3. 在"文件列表"点击文件 → 自动在"编辑器"打开

### 文件类型与编辑器

GeWu 根据文件扩展名自动选择合适的编辑器/查看器：

| 文件类型 | 扩展名 | 处理插件 |
|----------|--------|----------|
| 文本/代码 | .txt .json .ts .py .rs .sh 等 | editor |
| Markdown | .md .markdown | markdown-editor |
| 图片 | .png .jpg .jpeg .gif .svg | image-viewer |
| PDF | .pdf | pdf-viewer |
| Word | .docx | docx-viewer |
| Excel | .xlsx .xls .xlsm | xlsx-viewer |
| 网页链接 | .url | webview |

## 功能介绍

### 文件浏览

**目录树导航**：
- 点击文件夹展开/折叠
- 单击文件夹 → 文件列表自动刷新
- 右键文件夹 → 在资源管理器中打开

**文件列表**：
- 支持按名称、类型、大小、修改时间排序（点击列头切换）
- 支持文件名筛选（顶部搜索框）
- 右键文件 → 重命名、删除、移动到分类、外部打开
- 双击文件 → 在编辑器中打开
- 行内重命名：右键 → 重命名，直接输入新名称回车确认

**新建文件**：
- 在文件列表顶部点击"新建文件"按钮
- 选择文件模板（Markdown、纯文本、TypeScript 等）
- 输入文件名，自动创建并打开

### 注册外部目录

目录树支持注册知识库根目录之外的目录，点击目录树工具栏的「注册外部目录」按钮，选择类型后输入路径（也可点击"浏览"直接选择文件夹）：

- **收件箱（inbox）**：库外"暂存区"，如桌面、下载目录。用于暂存待整理的文件，可与库内目录做移动/复制交互；不承载 .pack 知识包特性
- **共享资源库（resource）**：多库共享的素材目录。目录内的知识包（.pack）为**只读**——多个知识库可同时引用，但不能直接修改。需要编辑某个包时，打开它并选择「复制到我的库」，副本会复制到当前知识库内（原目录保持不变，其他库仍可继续引用）

**路径支持系统变量**：注册路径可直接输入 `%USERPROFILE%`、`%OneDrive%` 等系统环境变量（如 `%USERPROFILE%\Desktop`），换电脑或更换用户名后会自动展开到新环境，无需重新注册。

**提示**：知识库根目录下的子目录无需注册，可直接在目录树中使用；「注册外部目录」仅用于库外目录。

### 文件编辑

**文本编辑器**：
- 支持所有文本类文件
- 点击"编辑"按钮进入编辑模式
- `Ctrl+S` 保存修改
- "取消"按钮放弃修改并还原

**Markdown 编辑器**：
- 实时预览 Markdown 渲染效果
- 支持标题、列表、代码块、引用、粗体/斜体、行内代码
- 编辑模式与预览模式可切换

**二进制文件查看器**：
- 图片：支持缩放、平移
- PDF：分页浏览
- Word/Excel：只读查看（暂不支持编辑）

### 分类与标签

**分类管理**（organizer 插件）：
- 树形结构组织分类
- 支持多级嵌套
- 拖拽文件到分类进行归类
- 右键分类 → 新建子分类、重命名、删除

**标签管理**：
- 为文件打多个标签
- 按标签筛选文件
- 标签支持树形结构（如 `工作/项目A`）

### 主题切换

支持三种主题，通过顶部工具栏切换：
- **浅色**：白底黑字，柔和色调（默认）
- **深色**：暗色背景，护眼
- **彩色**：鲜艳配色方案

### 容器布局

- **新建容器**：`Ctrl+N` 或工具栏"+"按钮
- **拖拽调整宽度**：拖动容器间的分隔条
- **折叠/展开**：点击容器标题栏的折叠按钮
- **最大化**：点击容器标题栏的最大化按钮
- **平均分布**：工具栏"📏"按钮
- **容器清单**：工具栏"▶"按钮，查看所有容器状态

### 命令面板

按 `Ctrl+P` 打开命令面板：
- 搜索并执行命令
- 显示插件贡献的快捷操作
- 支持模糊搜索

### 右键菜单

右键点击文件/文件夹/分类时，会弹出上下文菜单：
- 文件：重命名、删除、移动到分类、外部打开、复制路径
- 文件夹：在资源管理器中打开
- 分类：新建子分类、重命名、删除

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+P` | 打开命令面板 |
| `Ctrl+N` | 新建容器 |
| `Ctrl+S` | 保存文件（编辑模式下） |
| `Ctrl+Shift+B` | 打开浏览器（webview 插件） |
| `Esc` | 关闭弹窗/取消编辑 |

## 常见问题

### 数据存储在哪里？

所有数据存储在本地，离线可用。知识库数据存储在对应的 SQLite 数据库（`<知识库目录>/.kmgr/kmr.db`）中。

### 如何备份数据？

直接备份知识库对应的文件夹即可。建议定期备份到外部存储或云盘。

### 如何安装第三方插件？

> 插件分发系统正在开发中。当前版本暂不支持第三方插件安装。
>
> 未来版本将支持通过插件市场或本地 npm 包安装第三方插件。

### 支持哪些文件类型？

| 类别 | 支持的扩展名 |
|------|-------------|
| 文本/代码 | .txt .json .xml .csv .log .yaml .yml .toml .ini .cfg .sh .bat .ps1 .py .js .ts .tsx .jsx .html .css .scss .less .sql .env .gitignore |
| Markdown | .md .markdown .rst .org .tex .adoc .asciidoc |
| 图片 | .png .jpg .jpeg .gif .svg |
| 文档 | .pdf .docx .xlsx .xls .xlsm |
| 网页 | .url |

### 文件内容显示乱码怎么办？

如果文件显示为乱码，可能是以下原因：
1. **二进制文件**：未知二进制文件会被路由到文本编辑器，建议使用"外部打开"
2. **编码问题**：尝试用其他编辑器另存为 UTF-8 编码后重新打开
3. **不支持的类型**：等待后续版本开发对应的查看器插件

### 如何重置布局？

在顶部工具栏点击"容器清单"按钮，可以查看和管理所有容器。如需恢复默认布局，删除所有容器后重启应用。

### 命令行工具有哪些？

GeWu 提供 `kmgr` 命令行工具，用于脚本和自动化场景：

```bash
kmgr init <path>              # 初始化知识库
kmgr scan <kb> --source <dir> # 扫描导入目录
kmgr add <kb> <file>...       # 添加文件
kmgr list <kb>                # 列出文件
kmgr search <kb> <keyword>    # 搜索文件
kmgr stat <kb>                # 统计信息
kmgr --json                   # JSON 输出格式
```

运行 `kmgr --help` 查看完整命令列表。
